# References

The source paper this project replicates:

> Du, Z., and Escanciano, J. C. (2017).
> Backtesting Expected Shortfall: Accounting for Tail Risk.
> *Management Science*, 63(2), 474–495.
> [DOI: 10.1287/mnsc.2015.2342](https://doi.org/10.1287/mnsc.2015.2342)

The methodology, formulas, and asymptotic results implemented in this
project follow the 2015 CAEPR working-paper version (Working Paper
2015-001, 11 January 2015), which is identical in substance to the
published *Management Science* article.

The full bibliography (sixteen entries covering the backtesting
literature, GARCH variants, and the neural baselines) is available in
`report/refs.bib`.
